# IT Career Guidance API

A FastAPI backend that provides career guidance for IT and data professionals based on user profiles and target jobs, powered by OpenAI.

## Features

- API endpoint for providing personalized career guidance
- Integration with OpenAI to generate career path recommendations
- Job data processing from CSV file
- Gap analysis, learning path, and timeline for career transitions

## Setup

### Prerequisites

- Python 3.8+
- OpenAI API key

### Installation

1. Clone the repository
2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
3. Create a `.env` file based on `.env.example` and add your OpenAI API key:
   ```
   OPENAI_API_KEY=your_openai_api_key_here
   ```

## Running the Application

Start the FastAPI server:

```
uvicorn app.main:app --reload
```

The API will be available at `http://localhost:8000`.

## API Endpoints

### Career Guidance

- **POST /career/guidance**
  - Provides personalized career guidance based on user profile and target job
  - Request body:
    ```json
    {
      "education": "Bachelor's in Computer Science",
      "skills": "Python, SQL, Basic Machine Learning",
      "experience": "1 year as Junior Developer",
      "certificates": "AWS Cloud Practitioner",
      "target_job": "Data Scientist"
    }
    ```
  - Response:
    ```json
    {
      "status": "success",
      "guidance": "Career guidance text generated by OpenAI...",
      "relevant_jobs_count": 1
    }
    ```

## API Documentation

Once the server is running, you can access:
